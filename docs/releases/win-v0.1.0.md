MacUnZip 的第一个 Windows 版本，支持 Windows 10 / 11（x64）。

## 功能

- 双击压缩包直接解压到原位置或默认目录，也可以改为打开主界面
- 主窗口：解压 / 压缩切换、拖放区、可点击并可设为默认的常用目录，可以把文件直接拖到某个目录上
- 资源管理器右键菜单：解压到此处、解压到…、打开…、快速压缩、压缩…（格式、压缩率、密码，可保存为默认）
- 解压：zip、rar（含加密包）、7z、tar、gz、xz、bz2、zst
- 压缩：zip（可加 AES-256 密码）、7z（可加密码）、tar.gz、tar.zst
- 8 套配色，跟随系统深浅色
- 版本检查与强制升级

## 安装说明

安装程序没有代码签名证书，首次运行时 SmartScreen 可能提示“已保护你的电脑”，请点“更多信息”→“仍要运行”。
安装到当前用户目录，不需要管理员权限。Windows 11 中右键菜单位于“显示更多选项”里。

## 已知限制

- 未签名
- 在资源管理器中多选文件后“快速压缩”，会合并为一个压缩包；但如果系统启动程序较慢，偶尔可能被拆成多个
- RAR 只能解压，不能创建
